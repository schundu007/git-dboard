# IsaacLab DevOps Dashboard

register: product

## Users
Infrastructure and ML DevOps engineers monitoring IsaacLab CI/CD pipelines. Expert users who glance at this 8+ hours a day. They need fast, scannable status — not explanations, not onboarding UX.

## Purpose
Central command surface for GitHub Actions workflows, nightly build tracking, container registry management, branch health, and SLURM/PBS cluster runners for the IsaacLab robotics simulation framework.

## Brand tone
Precise. Fast. Trusted. Every element earns its place. No decoration that doesn't carry information.

## Anti-references
- Generic AI-generated SaaS dashboards (gradient cards, glow borders everywhere, hero metrics with colored numbers)
- neon-on-black gaming aesthetic
- Grafana orange clone
- Navy + teal standard DevOps palette
- Anything that looks like it came from a ChatGPT prompt asking for a "dark dashboard"

## Principles
- Status communicates via color + icon + text — triple redundancy, never color alone
- Information density is a feature, not a problem
- Keyboard-first: command palette, consistent tab order
- Same component vocabulary everywhere: one button shape, one badge style, one table treatment
