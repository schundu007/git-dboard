Improvement Roadmap — 3-Phase Plan
From 16% Pass Rate to Elite CI/CD
Ordered by impact-to-effort ratio. Phase 1 alone restores nightly CI and unblocks postmerge. Each phase maps directly to a root cause from Slide 1.
Roadmap 2026
1
Fix ECR + Dependency Failures
Weeks 1–3
Targets #1 + #3 — restores nightly to 100%
Rotate ECR OIDC credentials — fix IAM trust policy; add nick-fields/retry (3×, 60s) to ECR push step in postmerge-ci.yml
Land PR #5571 — centralize all external pins in tools/python_deps.py; resolves packaging==23.0 conflict (#5558)
Fix isaaclab.sh exit codes — add post-install smoke test: python -c 'import isaaclab'; propagate real exit code (#5517)
Fix resolve-matrix.py fallback — unknown input → sys.exit(1), not silent all-matrix fallback in daily-compatibility
Guard GITHUB_OUTPUT in nightly-tags.sh — fail fast in CI if unset; prevents silent /dev/null writes
Land PR #5537 — fix workflow_call deprecation breaking nightly trigger in daily-compatibility.yml
2
Smart PR Gating — Eliminate GPU Waste
Weeks 4–7
Targets #4 — −60% GPU runner cost
Add dorny/paths-filter — classify PR as docs / tests / source / ci-config before any GPU runner is assigned
Gate GPU matrix in build.yml — if: needs.classify.outputs.source == 'true'; docs PRs → ubuntu-latest only, no GPU
Reduce PR matrix to 4 cells — latest Isaac Sim × 4 extensions on PRs; full 10-cell only on merge and nightly
BuildKit cache mounts — --mount=type=cache,target=/root/.cache/pip; reorder Dockerfile: requirements first, source after
Base image deduplication — build base once per Isaac Sim version; fan-out to 4 extensions in parallel from cache
Land PR #5563 — add conda/uv installation tests in CI; catch install regressions before reaching users
3
Blackwell GPU Support + Elite Observability
Weeks 8–12
Targets #2 — unblocks RTX 5090 / 5070 Ti users
Add sm_90a + sm_120 to CUDA arch — fix NVRTC -arch error (#5520); update CMakeLists / setup.py for Blackwell
Recompile TiledCamera kernel — add sm_120 target for GB202/GB203 silicon; resolves hang on RTX 5090 (#4951, #5001)
Add Blackwell runner to nightly matrix — RTX 5090 (GB202) cell in daily-compatibility.yml from Week 8
Resolve Isaac Sim 6.0 compat gaps — fix #5435 API breakages; make IS 6.0 the primary version in PR CI matrix
ECR push health check — hourly credential verification workflow; Slack alert on first failure before nightly runs
DORA metrics baseline — track deployment freq, lead time, MTTR, CFR; target Elite band by end of Q3
